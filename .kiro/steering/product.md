# Product Identity

## Purpose

「体重管理アプリ」は、日々の体重や体脂肪率のトラッキングといった健康管理行動に、「コレクションの収集」というゲーミフィケーション要素を取り入れたWebアプリケーションです。
Next.jsを利用したモダンで直感的なダッシュボードを提供し、Vercelを通じてシームレスにデプロイできるクラウドネイティブなサービス構成を目指します。

## Core Value

- **可視化と継続**: グラフを用いた変化の直感的な把握と、入力を続けることへのインセンティブ（コレクションアイテム解放）の両立。
- **ユーザビリティ**: いつでも、どのデバイスからでも素早く記録・確認できるWeb（PWA）アクセス体験。

## Key Capabilities

- **Health Log**: デイリーログ（体重・体脂肪率）の保存と取得、目標体重との差分計算。
- **Collection Setup**: 任意のコレクションテーマ・アイテムの作成と管理。
- **Evaluator Rule Engine**: 記録の更新に連動して進行度や達成状況を評価し、コレクションを解放するロジック。
- **Persistent Cloud Data**: Supabase（PostgreSQL）を使用したセキュアな履歴と設定の保管。

## Target Audience

- 何度も体重管理・ダイエットに挫折してきたが、ゲームをプレイするようにコツコツ集めるモチベーションで続けたいユーザー。
